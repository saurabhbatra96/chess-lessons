White exchanges on d5 and the position turns symmetrical. Many players treat this as an offer of a draw, and the player who accepts that view usually drifts into a worse game. There is still everything to play for, and Black's light-squared bishop, the French's traditional problem piece, has been set free.

```line
side: b
caption: The classical set-up, with ...Bg4
moves: 1.e4 e6 2.d4 d5 3.exd5 exd5 4.Nf3 Bd6 5.Bd3 Ne7 6.O-O O-O 7.Re1 Bg4 8.c3 Nd7
note: 3...exd5 | The bishop on c8 now has an open diagonal.
note: 5...Ne7 | The knight goes to e7 so that the f-pawn stays free, and ...Bg4 can pin White's knight.
note: 7...Bg4 | The bishop finds active work outside the pawn chain.
```

## Playing for a Win

If you want an unbalanced game, castle on the opposite side. Alekhine used this plan to beat strong players with the Exchange French. The queen goes to d7, the king goes long, and the kingside pawns start to run.

```line
side: b
caption: Queenside castling for a sharper game
moves: 1.e4 e6 2.d4 d5 3.exd5 exd5 4.Bd3 Nc6 5.c3 Bd6 6.Nf3 Bg4 7.O-O Nge7 8.Re1 Qd7 9.Nbd2 O-O-O
note: 4...Nc6 | The knight develops and keeps an eye on d4.
note: 9...O-O-O | The kings now stand on opposite wings, and the game is no longer symmetrical.
```

If White plays an early c4, the game changes character, and one side will have an isolated pawn. You will find those plans in the lesson on the isolated queen pawn.
